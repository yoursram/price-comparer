# Price Comparator

## Overview
Price Comparator is a tool that helps users compare prices of products from various online stores. The aim is to find the best deals available online.

## Features
- Compare prices from multiple stores
- Filter results based on product type
- User-friendly interface

## Installation
To install, clone the repository and run the following command:

```
npm install
```

## Usage
Run the application using:

```
npm start
```
